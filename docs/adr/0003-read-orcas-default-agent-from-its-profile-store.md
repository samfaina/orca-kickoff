# Read Orca's default agent from its profile store

`orca worktree create --prompt` requires `--agent`, and neither the CLI nor the plugin API exposes Orca's default agent. Each project has an agent choice: "Orca default", a named agent, or no agent. "Orca default" is resolved by reading `defaultTuiAgent` and `disabledTuiAgents`, read-only, from Orca's internal `profile-state.db` (with the older `orca-data.json` as a fallback). This depends on Orca's private storage layout and can break on any Orca update. So when the value cannot be read, Start fails and tells the user to choose an agent in the panel. It does not silently fall back to `claude`, which is what the original plugin did. Orca's rule of picking the first installed agent when the preferred one is missing cannot be reproduced, and is not attempted.
