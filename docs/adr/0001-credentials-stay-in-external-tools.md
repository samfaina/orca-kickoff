# Credentials stay in external tools

Kickoff stores no tokens or passwords. Each provider reads its tracker through a tool where the user has already logged in: `gh` for GitHub, Orca's own Jira connection (`orca jira`) or `twg` for Jira, and Orca's own Linear connection (`orca linear`) for Linear. Plugin storage holds only configuration and prompt templates. Calling an API directly with a token kept in plugin storage would have been simpler to code, but it would leave secrets in a store that was never meant for them and make Kickoff responsible for refreshing them. Linear is read through Orca's connection, so its API key stays in Orca; if that support falls short, the alternative is a provider that reads a Linear token from an environment variable or from Orca's `secrets:own` keychain store, never from plugin storage.
